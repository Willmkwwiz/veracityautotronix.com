Veracity Autotronix
​Welcome to the official web platform repository for Veracity Autotronix. This project powers the primary web application for Veracity Autotronix, serving as a hub for automotive electronics diagnostics, high-performance battery supply, motorcycle battery maintenance, and autotronix solutions.
​📄 Project Overview
​The Veracity Autotronix website is a high-performance, responsive static web platform built to highlight our services, introduce leadership and key team members, handle client inquiries, and integrate interactive elements like the custom Veracity UI widget.
​🌟 Key Features
​Landing Hub (index.html): Quick overview of offerings, promotional content, and site navigation.
​Company & Leadership (about.html): Profiles of key team members including Daiton Kapoto, Tawonamo Kamwendo, and Tennyson Misomali alongside our company values and history.
​Services Portfolio (services.html): Comprehensive service details covering Willard and GP battery distribution, specialized motorcycle battery servicing, and autotronix diagnostic diagnostics.
​Client Engagement (contact.html): Direct contact interface and location details.
​Interactive UI Components (veracity-widget.js, script.js): Modular client-side scripts for dynamic site features and custom widget support.
​SEO & Search Indexing: Optimized via sitemap.xml, robots.txt, and standard metadata tags.
​Custom Domain Routing: Preconfigured CNAME file for seamless deployment.
​🛠️ Tech Stack & Assets
​Frontend: HTML5, CSS3, JavaScript (ES6+)
​Media & Assets: WebP/JPEG optimized images and embedded MP4 promotional media.
​Domain & SEO Setup: Custom domain mapping (veracityautotronix.com) & search engine indexing rules.
