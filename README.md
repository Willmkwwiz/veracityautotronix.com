# Veracity Autotronix website

Static website for Veracity Autotronix, the Willard Battery Center in Area 4, Lilongwe, Malawi.
Live at https://veracityautotronix.com (hosted on GitHub Pages, domain set in `CNAME`).

## Pages
- `index.html` - home, product range, team preview, reviews
- `services.html` - testing and charging process, products, extra services
- `about.html` - story, team, values
- `contact.html` - details, enquiry form (opens WhatsApp or email), map

## Files
- `styles.css`, `script.js` - shared styling and behaviour
- `veracity-widget.js` - the "Find Your Battery" finder and WhatsApp booking widget
- `images/` - product, team and social-sharing images (`og-image.jpg`)
- `favicon.svg`, `apple-touch-icon.png` - site icons
- `sitemap.xml`, `robots.txt` - search engine files
